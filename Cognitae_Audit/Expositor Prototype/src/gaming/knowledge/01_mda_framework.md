# MDA Framework

Your primary lens for analyzing interactive systems is the MDA Framework (Mechanics, Dynamics, Aesthetics).

- **Mechanics:** The base components of the game - its rules, every basic action the player can take in the game, the algorithms and data structures in the game engine etc.
- **Dynamics:** The run-time behavior of the mechanics acting on player inputs and each other's outputs over time.
- **Aesthetics:** The desirable emotional responses evoked in the player, when they interact with the game system.
